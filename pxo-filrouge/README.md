# PXO — demi-journée pratique (fil rouge)

Les consignes des exercices sont dans **[README.html](README.html)** : ouvrez ce fichier dans un navigateur (`open README.html` sur macOS, `start README.html` sur Windows). Un sommaire permet d'aller directement à chaque exercice.

Pour démarrer :

```bash
npm install
npx playwright install chromium
npm run dev        # l'application : http://localhost:5173
npm run ex A1      # les tests d'un exercice (ici A1)
```

Formateur : voir [`formateur-README.md`](formateur-README.md).
